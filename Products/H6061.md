10-panel RGBIC wall. Same GATT family as the [H6088](H6088.md) cubes, **different segment-mask bytes**. Do not copy the cube table onto this light.

Packet builders and a bleak CLI live in [`Products/H6061`](H6061/). `python test_packets.py` checks the hex dumps below. `python cli.py frames` prints them; `paint` / `status` talk to a real Hexa (force-quit the Govee app first).

Longer write-up: [mpalczew/govee-ble-segments](https://github.com/mpalczew/govee-ble-segments). Captured 2026-07 / 2026-08 with an nRF sniffer plus live paints.

## Transports

| Transport | Works | Note |
|---|---|---|
| Bluetooth LE | yes | per-panel color and status below |
| Govee LAN API | whole-device only | discovery / `devStatus` / uniform color. Segments are BLE. |
| Encryption | none | plaintext 20-byte frames |

ADV name: `Govee_H6061_*`.

## GATT

```
service      00010203-0405-0607-0809-0a0b0c0d1910
control      00010203-0405-0607-0809-0a0b0c0d2b11
notify       00010203-0405-0607-0809-0a0b0c0d2b10
```

Subscribe to notify (`2b10` CCCD `01 00`) before sending `aa` queries. A GATT **read** of `2b10` / `2b11` is not live state.

The Govee app holds the only central. Force-quit it before your controller connects, or writes fail.

## Frame format

20 bytes. Byte 19 = XOR of bytes 0..18.

```
0x33   command
0xaa   status query (reply comes back on notify with the same opcode)
```

## Panel numbering (power-first)

**1 = power injector** (cable end), then along the physical snake to **10**. The app does not show these indices.

Color mask is a **u16 big-endian at bytes 9–10**.

| Panel | Mask (bytes 9–10) |
|---:|---|
| 1 | `0x0100` |
| 2 | `0x0200` |
| 3 | `0x0400` |
| 4 | `0x0800` |
| 5 | `0x1000` |
| 6 | `0x2000` |
| 7 | `0x4000` |
| 8 | `0x8000` |
| 9 | `0x0001` |
| 10 | `0x0002` |

## Commands (`0x33`)

### Power

```
33 01 01 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 33   on
33 01 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 32   off
```

### Global brightness

`33 04 LL` with `LL` = 0–100 (`0x00`–`0x64`). Dims the wall without changing segment hues.

```
33 04 64 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 53   100%
33 04 0a 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 3d   10%
```

`33 04 00` is **dim to 0**, not a query.

### Segment color

```
33 05 15 01 RR GG BB 00 00 MH ML 00 00 00 00 00 00 00 00 XX
mask = (MH << 8) | ML
```

Panel 1 red:

```
33 05 15 01 ff 00 00 00 00 01 00 00 00 00 00 00 00 00 00 dc
```

Panel 10 cyan:

```
33 05 15 01 00 ff ff 00 00 00 02 00 00 00 00 00 00 00 00 20
```

### Segment brightness

```
33 05 15 02 LL MH ML …
```

`LL` = 0–100. Mask sits at bytes 5–6 (same BE bits as color). This is independent of `33 04`. A wall that still looks dim at LAN 100% usually has leftover per-segment levels.

## Status reads (`0xaa`)

Write `aa {cmd} …` on the control char. Matching `aa {cmd} …` arrives on notify. Keep reading until the opcode matches; leftover frames will otherwise look like garbage.

| Field | Query | Reply |
|---|---|---|
| Power | `aa 01` | `aa 01 {0\|1}` |
| Live wall brightness % | `aa 04` | `aa 04 {0–100}` |
| Mode | `aa 05` | `aa 05 15` + zeros after a multi-seg paint. **Not** live panel RGB. |
| Segment dump | `aa a5 {page}` | see below |
| Version | `aa 06`, `aa 20`, `aa 21` | ASCII |

`aa 12` is a capability blob (often `ff 64 …`), not dim.

### Segment dump

```
write:  aa a5 NN 00 … XX
reply:  aa a5 NN  {LL RR GG BB}×4  XX
NN = 01, 02, 03
```

- Skip page **0** (aliases page 1 here).
- Pages 1–3 = 10 panels + two zero pads, power-first order.
- `LL` is per-segment brightness 0–100. Whole-wall dim is the separate `aa 04` value.

Example (mint wall, all `LL=100`):

```
aa a5 01 64 00 ff ae 64 00 ff b7 64 21 ff 97 64 40 ff af 4e
aa a5 02 64 a1 ff e0 64 a1 ff e0 64 40 ff af 64 21 ff 97 54
aa a5 03 64 00 ff b7 64 00 ff ae 00 00 00 00 00 00 00 00 15
```

## Gotchas

- One BLE central. Phone app connected ⇒ your writes lose.
- nRF sniffer only follows ATT if it sees `CONNECT_IND`. Start sniff **before** the phone connects.
- After a multi-color BLE paint, LAN `colorwc` may not overwrite every panel. Paint all 10 segments for a solid look.
- Do not force `33 04 64` on every reconnect; it flashes the wall mid-scene. Power on → paint segments → set wall dim once.
