RGBIC Cube Wall Sconces, six daisy-chained cubes. Same `33 05 15` opcode family as the [H6061](H6061.md) Hexa, but the mask is a single bit at **byte 12**, not the Hexa u16 at bytes 9–10. Hexa masks do not light these cubes.

Probed by painting six distinct colors and reading physical order. Same one-central rule as Hexa: force-quit the Govee app first.

Check the `Products/H6088` folder for example scripts (`scan.py`, `paint.py`, `status.py`). Edit `DEVICE_NAME` at the top of each file.

## Transports

| Transport | Works | Note |
|---|---|---|
| Bluetooth LE | yes | per-cube color and status below |
| Govee LAN API | whole-device only | segments are BLE |

ADV name looks like `Govee_H6088_*`.

## GATT

```
service      00010203-0405-0607-0809-0a0b0c0d1910
control      00010203-0405-0607-0809-0a0b0c0d2b11
notify       00010203-0405-0607-0809-0a0b0c0d2b10
```

Write without a response. Subscribe to notify before `aa` queries.

## Frame format

20 bytes, last byte XOR of the first 19. Same as [H6061](H6061.md).

```
0x33   command
0xaa   status query
```

## Cube numbering

Number along the daisy chain. For a wall map, pick a stable convention (for example 1 = left when facing the desk) and stick to it.

| Cube | Mask bit (byte 12) |
|---:|---|
| 1 | `0x01` |
| 2 | `0x02` |
| 3 | `0x04` |
| 4 | `0x08` |
| 5 | `0x10` |
| 6 | `0x20` |

This is the H6046-style LE bitmask, not the Hexa BE u16.

## Commands

### Power

```
3301010000000000000000000000000000000033   on
3301000000000000000000000000000000000032   off
```

### Global brightness

0–100. Dims the row without changing cube hues. `330400…` is dim to 0, not a query.

```
3304640000000000000000000000000000000053   100%
```

### Cube color

```
33 05 15 01 RR GG BB 00 00 00 00 00 MM 00 00 00 00 00 00 XX
MM = LE bit (0x01 … 0x20) at byte index 12
```

```
33051501ff0000000000000001000000000000dc   cube 1 red
3305150100ffff00000000002000000000000002   cube 6 cyan
```

### Cube brightness

```
33 05 15 02 LL MM …
```

`LL` at byte 4; mask bit at byte 5.

Hold the adapter for the whole 6-write paint. A long scan in the middle leaves the first cubes updated and the rest stale.

## Reading current values

Same path as Hexa: write query, read matching notify.

| Field | Query | Reply |
|---|---|---|
| Power | `aa 01` | `aa 01 {0\|1}` |
| Live row brightness % | `aa 04` | `aa 04 {0–100}` |
| Mode | `aa 05` | `aa 05 15` + zeros after a native multi-cube paint. Not live cube RGB. |
| Cube dump | `aa a5 {page}` | four `LL RR GG BB` slots |

`aa 12` is a capability blob, not dim. Skip page 0 (zeros on this SKU). Pages 1–2 are 6 cubes plus pads.

LAN uniform color may not clear a multi-cube BLE paint. Re-paint all six cubes for a solid look.
