E12 / A19-class RGB bulb. Solid color only. **Not a segment device.** Two sockets on a fixture are two BLE peripherals: two connects, two `e701`/`e702` handshakes, two status polls.

This one is session-encrypted, unlike [H6061](H6061.md) / [H6088](H6088.md). Do not send plaintext `33` / `aa` frames after auth, and do not send Hexa/sconce `33 05 15` masks. The phone order when turning on is color, then power on, then brightness.

Check the `Products/H600B` folder for example scripts (`scan.py`, `paint.py`, `status.py`). `utils.py` also replays a captured auth + power-off + red frame if you run it directly (`pycryptodome`).

## GATT

```
service      00010203-0405-0607-0809-0a0b0c0d1910
control      00010203-0405-0607-0809-0a0b0c0d2b11
notify       00010203-0405-0607-0809-0a0b0c0d2b10
```

Write without a response. A GATT read of `2b10` is often static `01 02`. Not live state.

## Encryption

PSK used only for auth: `MakingLifeSmarte` (16 bytes; same family as GoveeBTTempLogger).

1. `e701` / `e702` handshake, encrypted under the PSK.
2. Session key is bytes 2–17 of the decrypted `e701` reply.
3. Later frames: XOR-stamp the 20-byte plaintext, AES-128-ECB on bytes 0–15, RC4 on bytes 16–19, using the session key.
4. Decrypt notifies the same way. Keep reading until the **decrypted** opcode matches; leftover auth frames decode as garbage.

## Commands (plaintext, then encrypt)

| Action | Prefix |
|---|---|
| Power | `33 01 01` / `33 01 00` |
| Brightness | `33 04 LL` (`LL` = 0–100) |
| Solid RGB | `33 05 0d RR GG BB` |

The sub-command is `0x0d`, same idea as [H6004](H6004.md). There is no `33 05 15` segment paint.

## Reading current values

Subscribe to notify, then query. Same `aa` opcodes as the Hexa, but both directions are encrypted.

| Field | Query | Reply |
|---|---|---|
| Power | `aa 01` | `aa 01 {0\|1}` |
| Live brightness % | `aa 04` | `aa 04 {0–100}` |
| RGB | `aa 05` | `aa 05 0d RR GG BB` |
| Version | `aa 06`, `aa 20`, `aa 21` | ASCII |

`aa a5` replies are zeros. `aa 12` is a capability blob, not dim. `33 04 00` sets brightness to 0.

A ceiling-fan pair is two MACs. Shared "fixture brightness" in a UI is your aggregation (for example max of the two `aa 04` values when either is on).
